Lisa aktsia

Ostuhind sisesta aktsia enda valuutas (USA aktsiatel dollarites). Selle järgi arvutatakse kasum/kahjum.

Hinnaandmed

Päris hinnad tulevad Finnhubist. Selleks on vaja tasuta API võtit:

  1. Loo tasuta konto: finnhub.io/register
  2. Kopeeri Dashboardist API Key.
  3. Kleebi see siia. Võti salvestub ainult sinu seadmesse.

Ilma võtmeta töötab äpp demorežiimis simuleeritud hindadega, et saaksid kõike kohe proovida.

Hinnad uuenevad iga minuti tagant, kui leht on lahti. Tasuta võti toetab peamiselt USA aktsiaid ja ETF-e. Valuutakursid eurodesse tulevad Euroopa Keskpangast (Frankfurter).
